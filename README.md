# E-commerce-Sales-Customer-Analytics-Dashboard

## 📌 Project Overview

This project analyzes e-commerce sales and customer data to understand overall business performance, sales trends, product categories, and customer purchasing behavior.

I used SQL to perform the data analysis and Excel to create an interactive dashboard that presents the key findings in a simple and easy-to-understand way.

The main goal of this project was to turn raw sales data into useful business insights that can support better decision-making.

---

## 🎯 Objectives

- Analyze overall e-commerce sales performance
- Track monthly sales trends
- Identify the best-performing product categories
- Find the top customers based on sales
- Compare repeat and one-time customers
- Present the analysis through a clear dashboard

---

## 🛠️ Tools & Technologies

- **MySQL** – Data storage, validation and analysis
- **Microsoft Excel** – Data analysis and dashboard creation
- **GitHub** – Project documentation and version control

---

## 📂 Dataset

The dataset contains **1,000 e-commerce orders** from 2025 and covers **222 unique customers**.

### Dataset Columns

| Column | Description |
|---|---|
| Order_ID | Unique identifier for each order |
| Order_Date | Date when the order was placed |
| Customer_ID | Unique customer identifier |
| Customer_Name | Customer name |
| Product | Product purchased |
| Category | Product category |
| Quantity | Number of units purchased |
| Unit_Price | Price per unit |
| Sales | Total sales value |
| Region | Customer's region |
| Payment_Method | Payment method used |

---

## 🔍 Data Validation

Before performing the analysis, I performed basic data validation checks using SQL.

The checks included:

- Missing values
- Duplicate order IDs
- Incorrect sales calculations
- Invalid quantities or prices

This helped ensure that the data was consistent before using it for analysis.

---

## 📊 Key Analysis

The project focuses on five main areas:

### 1. Overall Business KPIs

The dashboard tracks:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value

### 2. Sales by Category

Analyzes revenue generated by each product category and helps identify the strongest-performing categories.

### 3. Monthly Sales Trend

Tracks sales performance month by month to identify changes and trends throughout the year.

### 4. Top 10 Customers

Identifies the customers who contributed the highest amount of sales.

### 5. Repeat vs One-Time Customers

Classifies customers based on their order frequency to understand customer purchasing behavior.

## 💡 Key Insights

Some of the insights identified from the analysis include:

- **₹36.15 lakh** in total revenue was generated across 1,000 orders.
- The dataset contains **222 unique customers**.
- **Home & Kitchen** and **Electronics** were the highest-revenue categories.
- **September** recorded the highest monthly sales.
- A large majority of customers were classified as repeat customers.
- The highest-value customer contributed more than **₹1.5 lakh** in sales.
